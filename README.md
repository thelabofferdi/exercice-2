# exercice-2

Script Python interactif qui enchaîne trois actions avec l'API RodiumAi, sans SDK : chat, génération d'image et génération de vidéo.

## Installation

Python 3.11

```
pip install -r requirements.txt
```

## Configuration

```
cp .env.example .env
```

Puis mettez votre clé dans le fichier `.env`.

## Lancer

```
python main.py
```
